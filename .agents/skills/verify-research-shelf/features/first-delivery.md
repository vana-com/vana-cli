# First delivery

## Sub-features

- Start through Connect Vana with a fresh private store and browser.
- Read conversations through the actual app SDK route.
- Save before returning data, then render the saved revision.
- Acknowledge after rendering and retain content after reload and restart.

## How to get to it (user POV)

Open Research Shelf and choose **Connect Vana**. Live acceptance uses the actual
Account/Web approval. Controlled proof labels its approval-service responses as
fixtures.

## Driving it with the verifier

Run the parent skill's doctor and ordinary controlled command. Require matching
record identity and content in browser and durable-file evidence. Require the
acknowledged revision to match the saved and rendered revision. Record actual
network calls instead of inferring delivery from a status label.

For real consent and delivery, follow [live acceptance](../references/live-acceptance.md).
An approval URL, granted status or HTTP 200 alone cannot pass this recipe.

## Gotchas

The controlled lane runs the real consumer with substituted external services.
An old saved list does not prove a new connection. Payment without saving and
displaying the result is failed delivery.
